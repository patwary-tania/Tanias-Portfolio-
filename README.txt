TANIA AKHTER — PROFESSIONAL PORTFOLIO

CONTENTS
- index.html: the portfolio website (single HTML file; CSS and JavaScript are included).

HOW TO VIEW
1. Extract this ZIP archive.
2. Open index.html in a modern web browser.

HOW TO PUBLISH WITH GITHUB PAGES
1. Create or open a GitHub repository.
2. Upload index.html to the repository root.
3. In Settings > Pages, choose deployment from the main branch and the root folder.
4. Save and wait for GitHub Pages to publish the site.

CUSTOMIZE BEFORE PUBLISHING
- Replace sample education and experience entries with accurate details.
- Replace placeholder email address your.email@example.com in the contact section and mailto handler.
- Update the skills, projects, and profile information to match your background.

The contact form opens the visitor's email app; it does not send messages through a server.
